# 📱 手机软件不在这里

本目录 `desktop/` 是 **电脑端**。**手机端（安卓 App）不在这个目录里** ——
它是本项目的另一半，位于同一个仓库的 **`android/`** 目录：

- 仓库内路径：**[`../android/`](../android/)**
- 在线地址：<https://github.com/jiuerya/Neko-Spark/tree/master/android>

## ⚠️ 两个程序必须配合使用，缺一个都不完整

| | 位置 | 作用 |
|---|---|---|
| **电脑端** ← 你在这里 | [`desktop/`](.) | 电脑上的程序：仓库、浏览界面、导出、**本地服务 Hub** |
| **安卓端**（手机） | [`../android/`](../android/) | 手机上的 App：扫描相册、备份上传、从电脑恢复回相册 |

- **只有电脑端** → 手机照片无法自动传进来（只能用「设备 → 导入文件夹」手动导入）
- **只有安卓端** → App 连不上任何电脑、什么都做不了

> 🔑 **电脑端才是 Hub**：手机要连的是电脑端起的本地服务（HTTP `8787`）。
> 所以请**先在电脑上跑起来**，再在手机 App 里填电脑的局域网地址。
